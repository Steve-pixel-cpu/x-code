欢迎使用 x-code

首次使用需要先配置一个模型供应商, 填写后立即可用; 之后可随时在「设置 → 模型」里调整或追加。

设置
外观
主题外观
深色、浅色、跟随系统或亚克力材质
背景图片
自定义壁纸；配合亚克力主题有磨砂玻璃效果（PNG/JPEG/WebP，限 20MB）
壁纸亮度
压暗层强度：50 为默认观感，调高更亮、调低更暗（仅开启壁纸后生效）
50
界面字号
整体界面文字大小，像素值 10–24，默认 14，清空恢复默认
聊天内容字号
聊天消息（含代码块）的文字大小，像素值 10–24，默认 14，清空恢复默认，独立于界面字号
强调颜色
填写 16 进制色值（如 #8b80f9），输入即时生效
应用图标
替换侧栏与消息头像的标志；PNG/JPEG/WebP，建议 256×256（限 384KB）
通知
一轮任务结束时提醒你；提示音由浏览器现场合成，桌面通知在窗口最小化或切到别的会话时才会弹出
完成提示音
任务结束时播放一声短促的双音提示（手动停止不响）
桌面通知
任务结束时弹系统通知，点击可跳回对应会话；首次开启需允许浏览器通知权限
桌宠
桌面悬浮小窗，实时反映任务状态；兼容 Codex 宠物格式（pet.json + spritesheet 图集），把宠物文件夹放进下方目录即可识别，无需重启
桌宠开关
召唤或收起桌宠；按住宠物即可拖动，点击打招呼
宠物大小
调整桌宠悬浮窗的整体缩放，50%–200%；召唤中的宠物立即生效，重开后保持
100%
宠物列表
扫描安装目录与 ~/.codex/pets 中的宠物
模型
管理 API 供应商与模型列表；改动停顿后自动保存，立即可在会话中切换
行为
控制单轮任务循环的运行参数与命令权限
每轮最大迭代次数
单轮任务里模型连续调用工具的次数上限，达到后提前收束本轮；1–10000，默认 128，对新会话生效
命令白名单
匹配规则的 shell 命令不再弹权限确认，直接执行。规则按词序前缀匹配（如 "git push" 命中 "git push origin main"）；组合命令里每一段"命中规则或属于只读探查"即可放行，带命令替换或写文件重定向的段永远不命中。保存后立即对所有会话生效
命令拒绝清单
任一命令段命中这里的前缀即直接拒绝，优先于白名单与所有放行路径——用来表达例外：白名单放行 "git push" 的同时在这里加 "git push --force" 拦住强推。保存后立即对所有会话生效
敏感路径
写入这些路径（或被 rm/mv 等命令点名）时任何权限模式都会强制弹确认，白名单也不能豁免。内置已覆盖 .git、~/.ssh、shell 配置与本应用配置；这里可以加项目里的 secrets/、.env.production 等。相对路径按会话工作目录解析。保存后立即对所有会话生效
MCP 服务器
配置 MCP（Model Context Protocol）服务器，外部工具以 mcp__服务器__工具 的形式接入对话；改动停顿后自动保存并热生效，无需重启
Skills
技能包是一份 SKILL.md（可捆绑脚本/模板），任务匹配时模型自动读取并遵循。项目级技能放在 <项目>/.claude/skills/<名称>/，随仓库走；这里安装的是用户级技能（~/.x-code/skills/），装完即时生效，无需重启
记忆
Agent 在对话中自动沉淀的用户画像与长期事实，跨会话注入系统提示——它因此更懂你。这里添加的条目标记为"用户"来源，不会被自动淘汰；其余条目由 Agent 维护（写入时可在对话流里看到）
配置文件
所有用户级设置都存在这一个文件里（含模型供应商）；手动修改后需重启服务生效
settings.json
路径 ~/.x-code/settings.json
选择工作目录
